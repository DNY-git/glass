## Design decisions (this brief resolves them)

1. **New package `app/decisions/` = pipeline stage 8, pure (A2/A4/A5).** Imports allowed: stdlib `{__future__, dataclasses, typing, enum, json, hashlib}` plus `app.domain`, `app.models`, `app.forecasts`, `app.scenarios`, and itself. **No `app.features`** (Phase 6 criterion 17's both-direction pin stays green), no `app.storage`/`app.api`/`app.simulation`/`app.ingestion`/`app.validation`, no `os`/`sys`/`pathlib`/`io`/`time`/`random`/`sqlite3`/`http`/`urllib` (A1 adds the package to `PURE_PACKAGES` — strictly stronger). No wall clock, no I/O, no environment lookups.
2. **API (A2, binding): `build_decision_report(forecast, *, scenarios=())` — no `matches`, no time-like parameter exists to forget.** The report is a **serialization of an already cutoff-enforced artifact**: the cutoff was enforced once, inside `build_forecast`, when the Forecast was frozen; a renderer of frozen bytes **cannot see any history at all** — no new leakage surface is opened (this is stated in §10 pre-build, per A2). `TypeError` on a non-`Forecast`; `scenarios` keyword-only. The cheap poisoned-future byte-identity regression ships anyway (criterion 3, PLAN §6 layer 4 standing regression).
3. **No `FeatureVector` consumption (A2's lean default — resolved: NO).** Reports describe forecast structure, not features; importing `app.features` would break Phase 6 criterion 17's live pin. An override would require a named declared amendment — **not taken**.
4. **The record (A1/A5): one flat frozen `DecisionReport` + two nested frozen records** — `ScenarioComparison` and `ScenarioSpread` — field contracts pinned verbatim by criterion 2 (order: fixture block → provenance echoes → flags → disclaimer → estimate numbers → comparisons → spread → `content_hash`). `content_hash` computed at construction (`init=False`) under the package's **own** `canonicalization.py` (spec of record; **no import crosses the stage boundary**; `app/forecasts/canonicalization.py` untouched). The report **copies** the fields it presents (a rendering) and chains to the full forecast via `forecast_content_hash`; anything beyond the copied provenance (config, pooling, parameters) is reachable through that chain — full provenance without re-serializing `FittedParams` (quant no-objection).
5. **Report = view, NOT stored (A5/A8 — storage question resolved: NONE).** Generated in process; no sqlite table, no `SCHEMA_VERSION` bump, no API route, no CLI. Reports are deterministic, re-derivable **views** of a frozen forecast; ephemerality breaks nothing: Phases 9/11 join on **forecasts** (frozen, write-once, hashed, pinned — substrate complete), so Phase 7 adds nothing evaluation needs and **nothing here pre-scores**. Persistence/serving arrives only via a future brief with developer instruction.
6. **Vocabulary contract (A4).** Field names say estimate/probability/flag/caveat (`outcome_*`, `dropped_mass`, `flags`, `disclaimer`). **Uncertainty is expressed only by echoing** `convergence_status`, `insufficient_data`, `insufficient_teams`, `dropped_mass` at top level, plus the in-sample and synthetic caveats in the fixed disclaimer — **never** a numeric reliability band, never a CI/stderr/interval field (Phase 4's rule extends verbatim; `dropped_mass` is truncation disclosure, not an uncertainty band). **`mc_stderr` never enters a report**; scenario comparisons carry **analytic** `outcome_probs` only, never MC frequencies (analytic-first, §7e).
7. **"Disagreement" defined head-on (A1) — three components, none collapsed:** (i) **spread across labeled scenario hypotheticals** — per-outcome min/max/spread over the comparisons (min/max only; a mean is an invented ensemble); (ii) **flag-vs-plausible-number tension** — plausible-looking normalized probabilities presented beside screaming top-level flags, structurally (both visible, neither hidden, no threshold judging the tension — A6); (iii) the fixed disclaimer's explicit statement that **no second independent model exists**, so no cross-model agreement, no ensemble, and no agreement metric is ever presented (anti-ensemble answered, not silent).
8. **No thresholds or decision rules (A6 — threshold question resolved: NONE).** `constants.py` defines **exactly** `REPORT_VERSION` and `DISCLAIMER` (pinned by criterion 1); no numeric knob, no "flag when P(home)>X", no tuned constant exists anywhere in the package. This is the brief's position, not a default — thresholds would be arbitrary at best and fitting-on-outcomes = leakage into Phase 10's protected loop.
9. **Probabilities as estimate properties (A7).** The report states `outcome_home`, `outcome_draw`, `outcome_away` as copies of the forecast's analytic probabilities; **ordering is visible via field order (home, draw, away)** and nothing derives a favored side: no argmax/"most likely"/pick-shaped field exists (contract pin, criterion 2; vocabulary bans, criterion 14). Scenario `delta_*` fields are arithmetic differences between a labeled hypothetical and its own baseline — descriptive, never "value".
10. **Scenario handling (A1/A2).** Scenarios are optional; each must be built from **the forecast's own `FittedParams`** — a baseline failing frozen **value equality** is refused with `ValueError` (mirroring Phase 4's `simulate` provenance refusal); duplicate labels refused (`ValueError` — ambiguity never averaged); comparisons are evaluated through `scenario_matrix` + `outcome_probs` (the ONE cell-math path, analytic-first); transforms are echoed per entry so every hypothetical is fully labeled; entries are canonically ordered by label (shuffled scenario input ⇒ field-for-field identical report incl. `content_hash`); deltas computed at full precision, never rounded.
11. **Determinism:** no RNG, no wall clock, no environment reads (existing machinery + new AST criteria); identical `(forecast [, scenarios])` ⇒ field-for-field identical report including `content_hash` (criteria 2, 6, 7).
12. **Docs honesty — `docs/STATISTICAL-ASSUMPTIONS.md` §10 authored BEFORE any build code (A1/process; the §3/§7/§8/§9 pattern):** report contents, the comparison/no-collapse rule, the vocabulary contract, the no-scoring boundary, the synthetic caveat, and the continuity of §9's anchor — *"historical summaries … not evidence"* — carried forward (a report is a view of in-sample estimates, never new evidence). Updated to implemented reality at phase end, as usual.
13. **Four pre-sanctioned amendments (exact text below):** **A1** (hygiene: one `ALLOWED_APP_IMPORTS` entry **+ one line-neutral `PURE_PACKAGES` strengthening**, net **+1 line, 624 → 625**); **A2** (`tests/test_phase4_separation.py` pin 11 → 12, **832 → 833**); **A3** (`tests/test_phase5_separation.py` pin 11 → 12, **572 → 573**); **A4** (`tests/test_phase6_separation.py` pins updated **in place**, negative pin strengthened, **510 → 510**).
